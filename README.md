# TelPhone

TelPhone — портативная звонилка для Windows x64. Она отправляет команды на Android-смартфон по USB через ADB. Звонок идёт через SIM-карту смартфона, звук остаётся на телефоне.

## Запуск

1. Распакуйте сборку и откройте `TelPhone.exe`. Для запуска нужна Windows 10 или 11 x64. Среда .NET включена в сборку.
2. Если ADB ещё отсутствует, распакуйте [официальные Android SDK Platform-Tools для Windows](https://developer.android.com/tools/releases/platform-tools). Нажмите **Выбрать ADB** и укажите `adb.exe` из папки `platform-tools`. Можно также положить `adb.exe` и DLL из пакета в папку `adb` рядом с `TelPhone.exe`.
3. Включите отладку по USB, подключите телефон кабелем с передачей данных и подтвердите доверие на разблокированном телефоне. Отладка предоставляет авторизованному компьютеру расширенный доступ к смартфону. При отсутствии устройства проверьте драйвер Windows и USB-кабель.
4. Введите или вставьте номер и нажмите **Позвонить** либо Enter в поле ввода. Чтобы сбросить вызов на выбранном телефоне, нажмите **Завершить звонок**.

При отказе Android в прямом вызове TelPhone попытается открыть номер в звонилке. В этом режиме вызов нужно подтвердить на смартфоне. Во вкладке **История** сохраняются попытки вызова из TelPhone и результаты команд ADB. По записи «Команда вызова отправлена» можно судить только об отправке команды. История хранит даты в UTC и показывает местное время.

## Импорт контактов

Во вкладке **Контакты** нажмите **Импорт CSV или JSON**. Файл должен быть в UTF-8. Приложение пропустит некорректные строки и повторяющиеся номера после удаления пробелов, дефисов и скобок. В контактах и истории кнопку **Набрать выбранный номер** можно использовать, чтобы подставить номер в поле набора.

CSV с заголовком поддерживает запятую, точку с запятой или табуляцию. Заголовки `Имя` и `Телефон` также поддерживаются. Поле имени можно опустить.

```csv
name;phone
Анна Иванова;+79991234567
```

JSON принимает массив контактов либо объект с массивом `contacts`. Телефон передавайте строкой, чтобы сохранить начальный ноль и знак `+`.

```json
[
  {"name": "Анна Иванова", "phone": "+79991234567"}
]
```

## Данные

Контакты и история сохраняются в `data/telphone.db`, путь к ADB — в `data/settings.json`. Если папка приложения доступна только для чтения и портативной базы ещё нет, TelPhone использует `%LOCALAPPDATA%\TelPhone`. Для переноса данных закройте приложение и скопируйте папку данных.

## Сборка

Установите .NET 10 SDK на машине сборки и выполните команду из корня репозитория.

```powershell
.\scripts\build.ps1
```

Скрипт запускает тесты и публикует `artifacts/TelPhone-win-x64/TelPhone.exe`. ADB поставляется отдельно через официальный пакет Platform-Tools.

- `src/TelPhone` — интерфейс WPF и модель представления.
- `src/TelPhone.Core` — команды ADB, импорт контактов, нормализация и SQLite.
- `tests/TelPhone.Tests` — автоматические тесты команд, импорта и хранения.

Команды прямого вызова и завершения проверены вручную на Samsung Galaxy S24 FE. Для проверки собранного приложения запустите его под обычной учётной записью Windows, подключите телефон, импортируйте CSV и JSON, позвоните на второй телефон и завершите вызов. Проверьте, что попытка осталась во вкладке **История** после перезапуска.
