# usbPhone

usbPhone — портативная звонилка для Windows x64. Она отправляет команды на Android-смартфон по USB через ADB. Звонок идёт через SIM-карту смартфона, звук остаётся на телефоне.

## Запуск

[Скачать готовый usbPhone.exe или ZIP для Windows x64](https://github.com/KUPRYAKOFF/TelPhone/releases/latest).

1. Скачайте исполняемый файл или распакуйте ZIP, затем откройте `usbPhone.exe`. Для запуска нужна Windows 10 или 11 x64. Среда .NET включена в сборку.
2. Если ADB ещё отсутствует, распакуйте [официальные Android SDK Platform-Tools для Windows](https://developer.android.com/tools/releases/platform-tools). Нажмите **Выбрать ADB** и укажите `adb.exe` из папки `platform-tools`. Можно также положить `adb.exe` и DLL из пакета в папку `adb` рядом с `usbPhone.exe`.
3. Включите отладку по USB, подключите телефон кабелем с передачей данных и подтвердите доверие на разблокированном телефоне. Отладка предоставляет авторизованному компьютеру расширенный доступ к смартфону. При отсутствии устройства проверьте драйвер Windows и USB-кабель.
4. Введите или вставьте номер и нажмите **Позвонить** либо Enter в поле ввода. Чтобы сбросить вызов на выбранном телефоне, нажмите **Завершить звонок**.

При отказе Android в прямом вызове usbPhone попытается открыть номер в звонилке. В этом режиме вызов нужно подтвердить на смартфоне. Во вкладке **История** сохраняются попытки вызова из usbPhone и результаты команд ADB. По записи «Команда вызова отправлена» можно судить только об отправке команды. История хранит даты в UTC и показывает местное время.

## Интерфейс

- Дважды щёлкните контакт или выберите его и нажмите **Набрать номер**, чтобы сразу позвонить с подключённого телефона. Для сохранённого номера под полем набора отображается имя контакта.
- При разворачивании или растягивании окна почти на всю высоту монитора набор остаётся сверху, контакты открываются снизу.
- **Мини** оставляет номер и кнопки звонка. **Полный** возвращает остальные разделы. **Поверх окон** закрепляет окно в обоих режимах.
- В полном режиме доступны темы **Светлая**, **Тёмная** и **Ауспекс**. Приложение сохраняет тему, размерный режим и закрепление.

## Импорт контактов

Во вкладке **Контакты** нажмите **Импорт контактов** и выберите XLSX, CSV или JSON. После выбора файла выберите группу из списка или введите название новой. usbPhone присвоит её всем добавленным контактам. Пустое поле позволяет импортировать контакты без группы.

По умолчанию выбранная группа применяется и к уже сохранённым номерам из файла. При совпадении меняется только группа контакта. Снимите соответствующую галочку, если хотите пропускать такие номера. При поиске совпадений пробелы, дефисы и скобки в номерах игнорируются. Некорректные строки пропускаются.

В списке контактов можно фильтровать записи по группе и менять группу выбранного контакта. Чтобы убрать контакт из группы, очистите поле в окне **Сменить группу**.

XLSX можно загрузить напрямую. Приложение ищет столбцы **Фамилия Имя Отчество** и **Телефон** на видимых листах. Если из заголовка таблицы определяется группа, приложение предложит её при импорте. В XLSX у 11-значных российских номеров начальные `+7` и `7` заменяются на `8`.

CSV и JSON должны быть в UTF-8. CSV с заголовком поддерживает запятую, точку с запятой или табуляцию. Заголовки `Имя` и `Телефон` также поддерживаются. Поле имени можно опустить.

```csv
name;phone
Анна Иванова;+79991234567
```

JSON принимает массив контактов либо объект с массивом `contacts`. Телефон передавайте строкой, чтобы сохранить начальный ноль и знак `+`.

```json
[
  {"name": "Анна Иванова", "phone": "+79991234567"}
]
```

## Данные

Контакты и история сохраняются в `data/telphone.db`, путь к ADB — в `data/settings.json`. Если папка приложения доступна только для чтения и портативной базы ещё нет, usbPhone использует `%LOCALAPPDATA%\TelPhone`. Для обновления с TelPhone закройте старое приложение и поместите `usbPhone.exe` в ту же папку рядом с прежней папкой `data`.

## Сборка

Установите .NET 10 SDK на машине сборки и выполните команду из корня репозитория.

```powershell
.\scripts\build.ps1
```

Скрипт запускает тесты и публикует `artifacts/usbPhone-win-x64/usbPhone.exe`. ADB поставляется отдельно через официальный пакет Platform-Tools.

- `src/TelPhone` — интерфейс WPF и модель представления.
- `src/TelPhone.Core` — команды ADB, импорт контактов, нормализация и SQLite.
- `tests/TelPhone.Tests` — автоматические тесты команд, импорта и хранения.

Команды прямого вызова и завершения проверены вручную на Samsung Galaxy S24 FE. Для проверки собранного приложения запустите его под обычной учётной записью Windows, подключите телефон, импортируйте CSV и JSON, позвоните на второй телефон и завершите вызов. Проверьте, что попытка осталась во вкладке **История** после перезапуска.
